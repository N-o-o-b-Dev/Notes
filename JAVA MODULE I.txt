The Java Environment : 
 
	consist of 2 things 1.JDK [JAVA Development Toolkit], 2. JRE [Java Runtime 	Environment ]

JDK : it basically provide class, library, files, packages and etc that are necessary for execution of the java program.

java - > interpreter
javac - > Compiler
javap - > 0&1 into human code
java debugger - > NetBeans, visual studio code

Source code -> byte code [it platform independent] -> Machine Code
JVM main use case is converting Byte code into machine code
