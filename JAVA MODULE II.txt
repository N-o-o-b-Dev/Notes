Naming Rule:
	1. Don't start with number
	2. Don't use space
	3. Don't use Reserved keywords
	4. use only a-z, A-Z, Numbers/digits, Doller Sign($), Underscore(_)
	5. Java is Case Sensitive 
	

Example : 
	int ch = 10; -- OK
	int 1ch = 11; -- Not ok

Type Casting / Type Conversion

	1.Implicit/widening type conversion
		
		Compiler convert one data type to another without the help of Dev / 			programmer. 
			Example:	
					char alphabhat=a;
					int a= alphabhat;
					{ski value a=65} it changes automatically
			smaller datatype can be converted into larger datatype.
			short => char => int => long => float => double


	2.explicit / Narrowing Type conversion
		
		Here larger datatype into smaller datatype, and also it has to be done by 		programmer.	

		Example: 	

			double valueDouble = 8.73;
			int ValueInt = (Int)ValueDouble; // the value here shows only 8.
		if you do this type of conversion it may lose some data.

OPERATOR : 
		10 + 10 
		|  |  |
		|  |--|--> OPERATOR
		|     |
		|_____|----> OPERANDS



	1.Arithematic Operator : -
		
			-> [ +, -, *, /, % ]

	
 	2.PREFIX & POSTFIX : -

			->PREFIX
				++a, --a;
				It first increament the value and use it.


			->POSTFIX
				a++, a--;
				It means it use the value first and then use it;




	
	3.RELATIONAL OPERATOR : - 
		
		It tell us the relation between the two operands
		[ >, <, <=, >=, ==, != ]


	4.ASSIGNMENT OPERATOR :-
	
		[ = ]

	5.LOGICAL OPERATOR
	
		&& -> AND
			Both must be true then it return true
		|| -> OR
			any of the condition is true then it return true
		!  -> NOT 
			it return the opposite state [ !true becomes false ] 

	6. TERNARY OPERATOR :-
		
		Condition? expression-1:expression-2;
		
		if the condition is true  expression-1 will executed else expression-2

	7. SHIFT OPERATOR :-

		<< - Left shift 
			Example:	
				 10<<3 Means 10*2^3

		>> - Right Shift 
			 Example:	
				  10>>3 Means 10/2^3

	8. BITWISE OPERATOR :-
		BITWISE OR [|], BITWISE AND [&], BITWISE NOT[!]
